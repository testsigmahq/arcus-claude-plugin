The half of this that a cautious model gets wrong.

One step in this scenario has already been ruled unexpressible and written down
as Residue. Residue is a decided outcome rather than an outstanding one, so the
test is still delivered with the declined step standing as a marker. Losing the
whole test to a step somebody already correctly declined is the regression this
grader watches for, and it is the reading a careful model reaches on its own.
